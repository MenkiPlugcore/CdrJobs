# CdrJobs v0.9.0 — Adventurer API

Production-candidate hardening after all five standalone professions were implemented.

## Added
- Public `CdrJobsAPI`
- `ProfessionActionEvent`
- `ProfessionXpGainEvent`
- `ProfessionLevelUpEvent`
- Generic PlaceholderAPI level/xp/rank placeholders for every profession
- Generic profession activity counters in PlaceholderAPI
- SQLite schema metadata (`schema_version = 9`)
- Configuration validation warnings
- `/cdrjobsadmin diagnose`
- Dedicated API and production testing documentation
- CI artifact path fixed to follow current version automatically
- CI gate changed to `mvn clean verify`

## Integration readiness
`ProfessionActionEvent` intentionally fires only for gameplay actions that already passed the profession's anti-exploit checks. This is the future integration point for MENKIESTESParty projects and specialist systems.

## Status
Compile/CI success is required before promotion to v1.0.0. Runtime behavior still requires the test matrix in `docs/TESTING.md` on a Paper server.
