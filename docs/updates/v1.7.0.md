# v1.7.0 — Living Professions

## Goal

Make profession progression feel present during normal play without turning CdrJobs into an economy faucet or adding direct combat power creep.

## Architecture

`LivingProfessionsService` listens to accepted CdrJobs API events instead of raw block/entity events. The important consequence is that Momentum, Encounters, Milestones and session activity only see actions that the existing profession listeners already accepted after their anti-exploit checks.

The release does not replace the Five Paths services and does not change Public API v2.

## Profession Momentum

Momentum is tracked per player + profession for the current online session.

Default behavior:

- stage advances every 12 accepted actions;
- four stages;
- +2% profession XP per stage;
- maximum +8% XP;
- expires after 45 seconds without another accepted action for that profession;
- fractional bonus carry prevents low-value actions from losing percentage rewards to integer rounding.

Momentum is intentionally conservative. It rewards sustained legitimate activity without becoming the primary source of profession progression.

## Path Encounters

An accepted action may start one profession-specific timed objective if the player's Encounter cooldown is ready.

Default definitions:

| Profession | Encounter | Target | Time | Reward |
| --- | --- | ---: | ---: | ---: |
| Miner | Runic Vein | 8 | 45s | 320 XP |
| Farmer | Blessed Harvest | 20 | 60s | 300 XP |
| Hunter | Marked Prey | 6 | 90s | 350 XP |
| Lumberjack | Ancient Grove | 12 | 60s | 320 XP |
| Fisher | Restless Waters | 3 | 120s | 280 XP |

Encounter progress and expiry use existing profession counter/flag storage. Cooldowns use the existing ability cooldown table. Active Encounters therefore survive relog/restart without a schema migration.

Encounter rewards do not receive a Momentum multiplier and do not progress Contracts a second time.

## Fate Whispers

Players with an unlocked Fate Resonance may occasionally receive an atmospheric Resonance message while working one of the professions in that pair.

Fate Whispers are presentation only. They grant no damage, gathering drop, sell price, Vault money or other economy multiplier.

## Profession Milestones

Accepted actions are accumulated in the existing profession counter table under `living_actions`.

Default thresholds:

- 1,000
- 5,000
- 25,000
- 100,000

Each Five Path has its own milestone title progression. Milestones are cosmetic/status progression and do not grant direct power.

## Adventure Session

`/cdrjobs session` displays current-login statistics:

- accepted actions per profession;
- profession XP earned;
- level-ups;
- completed Path Encounters;
- current Momentum bonus;
- lifetime accepted actions and next milestone;
- active Encounter progress, if present.

Session counters are intentionally transient and reset after logout. Persistent progression remains in the canonical CdrJobs stores.

## Feedback Engine

The v1.7.0 feedback layer adds:

- coalesced next-tick actionbar feedback so the richer HUD wins over the legacy per-profession XP bar without rewriting the five stable profession listeners;
- profession progress bar;
- Momentum bonus;
- active Encounter progress;
- Path Ascended titles;
- Mastery Advanced titles;
- Contract Complete titles;
- Encounter and Milestone titles, sounds and particles.

## World Blacklist

`living-professions.world-blacklist` disables only the Living Professions layer in listed worlds. Normal profession validation, XP, Trials, Contracts and other CdrJobs core systems continue to run.

## Persistence / schema

No migration is required. Schema remains `9`.

New persistent keys reuse existing tables:

- `profession_counters`: `living_actions`, `living_encounter_progress`, `living_encounter_expires`
- `profession_flags`: `living_encounter_active`
- `ability_cooldowns`: `living_encounter_<job>`, `living_fate_whisper`
