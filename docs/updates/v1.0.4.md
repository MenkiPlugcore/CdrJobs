# CdrJobs v1.0.4 — Hunter QoL & Safety

## Goal
Make Hunter filtering and PvP rewards easier to configure while adding stronger anti-farm diagnostics.

## Mob filter
- `hunter.mob-filter.mode: ALL` lets listed mobs use custom XP and unlisted mobs use fallback XP.
- `hunter.mob-filter.mode: WHITELIST` rewards only entity types present in `hunter.xp`.
- `hunter.mob-filter.blacklist` always overrides both modes.

## PvP safety
Configurable gates:
- optional same-IP blocking
- minimum victim current online time
- minimum victim total playtime
- persistent same-victim cooldown
- rolling maximum rewarded kills per time window

Default same-IP blocking is disabled to avoid false positives for players sharing one connection.

## QoL
- `%cdrjobs_hunter_mob_kills%`
- `%cdrjobs_hunter_pvp_kills%`
- `/cdrjobsadmin hunterdebug <player>`
- separate Mob Kill / PvP Kill actionbar text

## Regression test
1. ALL mode: listed mobs use configured XP and unlisted mobs use fallback XP.
2. WHITELIST mode: unlisted mobs give no XP.
3. Blacklisted mobs give no XP in either mode.
4. Spawner/breeding exclusions still work.
5. Valid PvP kill gives XP.
6. Same-victim cooldown blocks repeat farming and survives restart.
7. Minimum victim online/playtime gates reject ineligible victims.
8. Reward-window limit blocks excessive rewarded PvP kills.
9. `hunterdebug` reports the most recent acceptance/rejection reason.
10. PAPI mob/PvP counters update only on rewarded kills.

## Database
No schema migration. Schema remains `9`.
