# CdrJobs v0.1.1 — Trials of the Deep

**Chapter:** Runebound Delver / Miner

This update makes Miner progression more deliberate. Levels and Fate Essence are no longer the only gates: powerful paths can require persistent Profession Trials.

## Profession Trials

### Trial of Stone
Requirement by default:
- Mine 500 natural ores

Purpose:
- Proves early Miner mastery
- Required before `Runic Surge` can be learned

### Trial of the Deep
Default requirements:
- Mine 1,200 ores below Y=0
- Mine 80 rare ores (Diamond, Emerald, Ancient Debris)
- Mine 10 Ancient Debris

Purpose:
- Endgame Miner mastery gate
- Required before `Heart of the Mountain` can be learned

Only natural ore counts. Player-placed ore is excluded using the persistent placed-ore database.

## Runic Surge

`Runic Surge` is CdrJobs' first active profession ability.

Default unlock requirements:
- Runebound Delver Lv.35+
- Runebreaker Rank II
- Trial of Stone completed
- 2 Fate Essence

Usage:
```text
/cdrjobs ability
```

Default effect:
- Duration: 20 seconds
- Haste I
- +25% Miner profession XP
- Cooldown: 300 seconds

Cooldown is persisted in SQLite, so restarting the server does not reset it.

## Upgrade behavior
New config and message defaults are merged into existing installations. Existing player levels, Fate Essence, skills and placed-ore tracking remain in the same SQLite database. New trial/cooldown tables are created automatically.

## Test checklist
- Natural ore grants Miner XP and Trial progress
- Player-placed ore grants neither XP nor Trial progress
- Placed ore remains blocked after server restart
- Trial of Stone completes at configured threshold
- Runic Surge cannot be learned before Trial of Stone
- Runic Surge applies Haste and XP bonus
- Runic Surge cooldown survives restart
- Trial of the Deep tracks all three requirements
- Heart of the Mountain remains locked until Trial of the Deep is complete
- `/cdrjobsadmin reset` clears trial and ability cooldown data
