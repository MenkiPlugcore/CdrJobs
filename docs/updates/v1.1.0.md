# CdrJobs v1.1.0 — Adventurer Profile

## Goal
Give players one clean summary of their complete Five Paths progression without changing the underlying progression schema.

## Player command
- `/cdrjobs profile`
- `/cdrjobs profile <online-player>`

The main `/cdrjobs` GUI also has an Adventurer Profile button.

## Profile data
The profile GUI displays:
- total profession level across all five Jobs
- highest profession + level
- Fate Essence
- completed Trials out of 10
- number of unlocked skill nodes
- awakened professions out of 5
- each profession's level, XP, rank and core activity statistic
- Hunter rewarded mob/PvP kill split

## PlaceholderAPI
New placeholders:
- `%cdrjobs_profile_total_level%`
- `%cdrjobs_profile_highest_profession%`
- `%cdrjobs_profile_highest_level%`
- `%cdrjobs_profile_trials_completed%`
- `%cdrjobs_profile_skills_unlocked%`
- `%cdrjobs_profile_awakened_count%`
- `%cdrjobs_profile_awakened_paths%`

Profile snapshots use a short in-memory cache to avoid repeated SQLite reads when several placeholders are rendered together.

## Compatibility fix
Legacy Miner placeholders are now resolved before generic `miner_*` parsing:
- `%cdrjobs_miner_trial_stone%`
- `%cdrjobs_miner_trial_deep%`
- `%cdrjobs_miner_total_ores%`

## Permissions
- `cdrjobs.use` — base plugin usage
- `cdrjobs.profile.others` — view another online player's public CdrJobs profile

## Regression checklist
1. `/cdrjobs profile` opens self profile.
2. Main menu Profile button opens self profile.
3. `/cdrjobs profile <player>` opens the requested online player's profile.
4. Total level equals the sum of the five profession levels.
5. Highest profession matches actual progression.
6. Trial count reflects Miner + Farmer + Hunter + Lumberjack + Fisher Trial flags.
7. Unlock one skill and verify skill count updates.
8. Unlock an awakened path and verify awakened count/name.
9. Verify Hunter mob/PvP split.
10. Test all new profile placeholders with PlaceholderAPI.
11. Test legacy Miner Trial placeholders.
12. Restart and verify the same persisted data is shown.

## Database
No schema migration. Schema remains `9`.
