# CdrJobs v1.3.0 — Profession Mastery

## Goal
Give every profession a lightweight endgame after Lv.100 without adding direct power creep.

## Progression
Once a Job reaches the configured max level, additional accepted profession XP is routed into Mastery XP instead of being discarded.

If one XP grant pushes a Job from Lv.99 to Lv.100, any XP remaining after the Lv.100 requirement is immediately routed into Mastery.

Default configuration:
```yaml
mastery:
  enabled: true
  max-tier: 10
  base-xp: 5000
  growth-per-tier: 2500
  tier-up-sound: true
```

Mastery tier requirement uses:
`base-xp + (current-tier × growth-per-tier)`.

Runtime safety clamps:
- max tier: 1–50
- base XP: minimum 1
- growth: minimum 0

## Rewards
Mastery is status/cosmetic progression only in v1.3.0. It does not grant:
- damage
- haste
- economy multipliers
- extra gathering drops
- PvP power

Tier titles:
- I–II: Initiate
- III–IV: Veteran
- V–VI: Elite
- VII–VIII: Ascendant
- IX: Paragon
- X+: Fatebound

Badges gain additional `✦` marks as Mastery advances.

## Commands
Player:
- `/cdrjobs mastery`
- `/cdrjobs mastery <job>`
- `/cdrjobs prestige [job]`
- `/cdrjobs top mastery <job>`
- `/cdrjobs top mastery-total`

Admin:
- `/cdrjobsadmin addmasteryxp <player> <job> <amount>`
- `/cdrjobsadmin setmastery <player> <job> <tier>`

`/cdrjobsadmin inspect` and debug export also include Mastery information.

## Persistence
Mastery uses the existing `profession_counters` table with metric `mastery_total_xp`.

Only one canonical total-XP value is persisted per player/Job. Tier and current progress are derived from that total and the current Mastery curve, reducing split-state corruption risk.

Schema remains `9`.

## Interaction with other systems
- Rite of Rebirth resets skills only and preserves Mastery.
- `resettrial` preserves Mastery.
- `resetjob` deletes the selected Job's profession counters and therefore resets that Job's Mastery.
- full player reset clears all Mastery.
- Hunter anti-farm rules still decide whether an action earns profession XP before that XP can feed Mastery.
- Miner/Farmer/Lumberjack/Fisher anti-exploit protections remain unchanged.

## Regression checklist
1. Set a profession to Lv.99 with XP near the Lv.100 threshold.
2. Grant enough valid XP to cross Lv.100 and verify overflow appears as Mastery XP.
3. At Lv.100, perform a normal profession action and verify level stays 100 while Mastery XP increases.
4. Repeat for all five Jobs.
5. Reach Mastery I and verify one tier-up notification only.
6. Use a large XP grant crossing multiple tiers and verify stored total XP/tier calculation remains correct.
7. Reach configured max Mastery and verify additional XP does not overflow the cap.
8. Restart the server and verify Mastery persists.
9. Change base/growth values, reload, and verify tier/current-XP is re-derived from canonical total XP without data loss.
10. Verify `/cdrjobs mastery` and `/cdrjobs mastery <job>`.
11. Verify profession Mastery leaderboard and total prestige leaderboard.
12. Verify all Mastery placeholders.
13. Run Rite of Rebirth and verify Mastery is unchanged.
14. Run `resettrial` and verify Mastery is unchanged.
15. Run `resetjob` and verify only that Job's Mastery is reset.
16. Verify full reset clears Mastery.
17. Re-run all Five Paths XP and anti-exploit tests.
18. Re-run Profile, leaderboard, and Rebirth regression checks.
