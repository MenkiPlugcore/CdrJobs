# CdrJobs v0.5.0 — Call of the Deep

Adds the fifth standalone profession: **Tidebound Angler (Fisher)**.

## Progression
- Cod, Salmon, Tropical Fish and Pufferfish XP
- Vanilla treasure catches receive configurable profession XP
- Ocean-biome catches tracked separately
- Lightweight anti-AFK: profession rewards pause after configurable stationary time until the player moves ~2 blocks

## Path
Tidewhisper, Swift Current, Abyssal Instinct, Ocean's Call, Ocean's Favor, Treasure Caller, King of the Tides.

## Trials
- Trial of the Tide: 250 catches
- Trial of the Abyss: 1000 catches, 50 treasures, 100 ocean catches

## Ability
Ocean's Call grants Luck and temporary profession XP bonus. Cooldown persists through restart.

## Testing
- Each configured fish gives XP
- Treasure catch increments treasure counter
- Ocean biome increments ocean catch counter
- Stationary longer than AFK threshold blocks only CdrJobs rewards, not vanilla fishing
- Moving ~2 blocks resumes rewards
- Trials and ability gates work
- Existing four profession data remains intact
