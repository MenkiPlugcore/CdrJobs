# CdrJobs v1.1.1 — Leaderboard & Profile QoL

## Goal
Add useful competitive progression views without turning leaderboard reads into constant main-thread database scans.

## Commands
- `/cdrjobs top <miner|farmer|hunter|lumberjack|fisher>`
- `/cdrjobs top total`
- `/cdrjobs top pvp`
- `/cdrjobs top activity <miner|farmer|hunter|lumberjack|fisher>`

## Ranking rules
### Profession leaderboard
Sorted by:
1. profession level descending
2. profession XP descending

### Total leaderboard
Ranks combined Five Paths level. Missing profession rows count as default level 1, matching normal CdrJobs progression semantics.

### Hunter PvP
Uses rewarded `pvp_kills`, so denied anti-farm kills do not inflate the ranking.

### Activity
- Miner: tracked natural ores
- Farmer: harvests
- Hunter: rewarded mob + PvP kills
- Lumberjack: natural logs
- Fisher: catches

## Cache
```yaml
leaderboards:
  limit: 10
  cache-seconds: 30
```

Runtime safety clamps:
- result limit: 3–20
- cache TTL: 5–300 seconds

Leaderboard queries use a dedicated SQLite read connection. Cached lists are reused until expiration and are invalidated by `/cdrjobsadmin reload`.

## Test checklist
1. Progress two players in the same Job and confirm ordering by level then XP.
2. Run `/cdrjobs top total` and compare against each player's five profession levels.
3. Confirm missing untouched profession rows still contribute their default level 1 to total ranking.
4. Earn valid Hunter PvP rewards and confirm `/cdrjobs top pvp` increments.
5. Trigger an anti-farm-denied PvP kill and confirm PvP ranking does not increment.
6. Test activity leaderboard for all five professions.
7. Run the same leaderboard repeatedly and confirm no console/database errors.
8. Change `leaderboards.cache-seconds`, reload, and confirm the new TTL is reflected.
9. Change `leaderboards.limit`, reload, and confirm result count changes within runtime clamp bounds.
10. Restart server and confirm rankings rebuild from persisted data.
11. Re-run v1.1.0 Adventurer Profile and PlaceholderAPI regression checks.
