# CdrJobs v0.2.0 — Verdant Awakening

Second standalone profession: **Verdant Keeper (Farmer)**.

## Added
- Farmer Lv.1–100 with fantasy rank titles
- Mature-crop XP for Wheat, Carrot, Potato, Beetroot, Nether Wart, Cocoa, Melon and Pumpkin
- Persistent per-location reward cooldown to reduce bone-meal spam
- Farmer Path of Ascension
- Greenblood, Rootbound, Sunpetal, Verdant Bloom, Blessing of Gaia, Spirit of the Grove, Verdant Dominion
- Rootbound auto-replant for supported crops
- Trial of Seed and Trial of Gaia
- Verdant Bloom active ability
- Farmer GUI and trial GUI
- Generic profession counters/flags stored in the existing `cdrjobs.db`
- Generic admin XP/level commands with job selector
- Farmer PlaceholderAPI level/rank placeholders

## Testing
- Harvest immature crop: no XP
- Harvest mature crop: XP awarded
- Immediately regrow/rebreak same location: blocked until configured location cooldown expires
- Rootbound replants supported crop at age 0
- Trial of Seed unlock gate works
- Verdant Bloom cooldown persists through restart
- Trial of Gaia and Verdant Dominion gate work
- Miner data remains unchanged after upgrade

## Commands
- `/cdrjobs farmer`
- `/cdrjobs trials farmer`
- `/cdrjobs ability farmer`
- `/cdrjobsadmin addxp <player> farmer <amount>`
- `/cdrjobsadmin setlevel <player> farmer <level>`
