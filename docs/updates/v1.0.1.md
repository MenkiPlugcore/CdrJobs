# CdrJobs v1.0.1 — Stability Patch

Maintenance release focused on regression safety and operator diagnostics. No profession balancing or database schema changes are introduced in this patch.

## Changes
- Added `/cdrjobsadmin inspect <player>` to inspect Fate Essence plus all five profession levels, XP and rank titles.
- Hardened admin command input validation.
  - `addxp` rejects zero and negative values.
  - `setlevel` rejects values outside the configured level range instead of silently clamping them.
  - malformed job/value syntax is rejected with explicit usage guidance.
- Hardened progression XP addition against `long` overflow.
- XP grants at max profession level now no-op instead of emitting misleading progression writes/events.
- `/cdrjobsadmin diagnose` now reports schema health against the expected schema version.
- `/cdrjobsadmin reload` persists newly merged default config keys before refreshing profession XP maps.
- PlaceholderAPI `*_xp_required` explicitly returns `0` at max level.
- Synced README, changelog and roadmap with the v1.0.0 production baseline and v1.0.1 candidate status.

## Compatibility
- Java 21.
- Paper API 1.21 family.
- Existing `cdrjobs.db` is preserved.
- SQLite schema remains version `9`.
- PlaceholderAPI remains optional.

## Regression checklist before stable release
1. `/cdrjobsadmin diagnose` reports version `1.0.1` and schema `9` as healthy.
2. `/cdrjobsadmin inspect <player>` correctly displays all five profession records.
3. `addxp` rejects `0` and negative values.
4. `setlevel` rejects values below `1` and above `settings.max-level`.
5. Valid `addxp` and `setlevel` still work for all five jobs.
6. `/cdrjobsadmin reload` reloads changed XP multipliers without restarting the server.
7. Max-level PlaceholderAPI `*_xp_required` returns `0`.
8. Restart the server and verify levels, XP, Fate Essence, skill ranks, trials and cooldowns remain intact.
9. Run the profession regression matrix from `docs/RELEASE_PROCESS.md`.

Do not promote this candidate to a stable GitHub Release until the real-server smoke test passes.
