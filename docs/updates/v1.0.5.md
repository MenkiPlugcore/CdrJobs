# CdrJobs v1.0.5 — Admin & Debug Tools

## Goal
Make production testing and support safer without requiring direct SQLite edits.

## New commands
- `/cdrjobsadmin addessence <player> <amount>`
- `/cdrjobsadmin setessence <player> <amount>`
- `/cdrjobsadmin resetjob <player> <job>`
- `/cdrjobsadmin resettrial <player> <job>`
- `/cdrjobsadmin resetcooldown <player> <job>`
- `/cdrjobsadmin export <player> [file|console|both]`

## Inspect improvements
`/cdrjobsadmin inspect <player>` now shows:
- Fate Essence
- all five profession levels, XP and ranks
- profession counters
- trial/flag state
- Miner trial state
- all unlocked skill ranks
- current persistent cooldowns

## Reset behavior
### resetjob
Resets only the selected profession:
- level/XP
- profession skill ranks
- profession trial state/counters
- profession Fate milestone claims
- profession cooldowns

Global Fate Essence and all other professions remain intact.

### resettrial
- Miner: resets Miner trial table only.
- Farmer/Hunter/Lumberjack/Fisher: their counters are also the source of Trial progress, so those profession counters and flags are cleared together.

### resetcooldown
Clears persistent cooldown records belonging to the selected profession. Hunter PvP same-victim cooldown records use the Hunter prefix and are included.

## Debug export
Default target directory:
`plugins/CdrJobs/debug/`

The report contains version/schema, UUID, Fate Essence, five profession snapshots, counters, flags, Miner trial progress, skills, cooldown timestamps and latest Hunter decision.

`console` prints the report through the plugin logger. `both` writes a file and logs it.

## Test checklist
1. Add/set Fate Essence and verify `/inspect`.
2. Reset one Job and confirm other professions and global Essence remain unchanged.
3. Reset one Trial and confirm intended Trial progress clears.
4. Reset cooldown and verify the selected ability can be activated again.
5. Export to file and inspect the generated text.
6. Export to console and confirm no exception.
7. Restart server and confirm untouched data remains persistent.
8. Re-run the five-profession regression matrix.

## Database
No schema migration. Schema remains `9`.
