# CdrJobs v1.0.0 — Five Paths

First standalone production release.

## Included professions
- Runebound Delver (Miner)
- Verdant Keeper (Farmer)
- Bloodfang Stalker (Hunter)
- Ironbark Warden (Lumberjack)
- Tidebound Angler (Fisher)

## Production baseline
- Java 21 / Paper API 1.21.4
- SQLite WAL persistence
- non-destructive schema creation and schema marker 9
- global Fate Essence with one-time milestone claim ledger per profession
- profession-specific anti-exploit protections
- Path of Ascension + trials + active abilities + awakened path for every profession
- optional PlaceholderAPI
- Public API v1 and Bukkit integration events
- `/cdrjobsadmin diagnose`
- CI release gate `mvn clean verify`

## Testing status
The source and packaged JAR must pass CI before distribution. Runtime balancing and server-specific plugin compatibility must still be validated using `docs/TESTING.md` on the target Paper server.

MENKIESTESParty integration is intentionally deferred until this standalone baseline has been exercised in real gameplay.
