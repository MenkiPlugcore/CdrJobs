# CdrJobs v1.6.0 — Public API v2 & GUI Refresh

`v1.6.0` is the standalone integration baseline before optional MENKIESTESParty work.

## Public API v2

- `CdrJobsAPI.API_VERSION = 2`.
- API v1 methods remain available.
- API is published through Bukkit `ServicesManager` and remains available through `CdrJobsPlugin#getApi()`.
- Added immutable snapshots for player/profile, profession, Mastery, Contracts, Fate Resonance and leaderboards.
- Added read access for skill ranks, statistics, flags, Trial progress and ability cooldown state.

New observational events:
- `SkillUpgradeEvent`
- `ProfessionAwakeningEvent`
- `TrialCompleteEvent`
- `MasteryTierUpEvent`
- `HunterPvpRewardEvent`
- `ContractCompleteEvent`
- `ContractClaimEvent`
- `RebirthEvent`

Existing `ProfessionActionEvent`, `ProfessionXpGainEvent`, and `ProfessionLevelUpEvent` remain supported.

## GUI Refresh

A non-destructive theme layer decorates empty GUI slots while preserving all existing buttons/PDC actions.

Themes:
- Main/Profile: cyan/light blue
- Miner: gray/purple
- Farmer: green/lime
- Hunter: red/purple
- Lumberjack: orange/yellow
- Fisher: blue/cyan
- Rebirth: purple/red

The same layer blocks drags into top CdrJobs inventory slots. Menu action exceptions are logged instead of silently ignored.

## Audit findings fixed

### Contract reward failure state
Previous flow marked a Contract claimed before reward delivery. A runtime reward failure could leave a claimed Contract without all rewards.

The new flow uses separate XP/Fate delivery checkpoints and finalizes `claimed` only after configured components succeed. Normal retry therefore avoids intentionally re-paying an already checkpointed component.

### GUI drag path
CdrJobs menus cancelled click events but did not explicitly block inventory drags into the top GUI. `GuiThemeListener` now closes that path.

### Silent menu exceptions
`MenuListener` previously swallowed broad exceptions. v1.6.0 records player/action/id context in console and shows a safe error message to the player.

### Reward-location table growth
Expired Farmer/reward-location cooldown rows previously had no pruning path. v1.6.0 prunes expired rows at startup.

### SQLite contention hardening
ProfessionStore now uses `PRAGMA busy_timeout=3000` in addition to WAL mode.

### Contract arithmetic
Contract progress uses saturating addition and percentage calculation no longer performs a potentially overflowing `long * 100` operation.

## Compatibility

- Java 21
- Paper API 1.21.4 dependency / `api-version: 1.21`
- PlaceholderAPI optional
- Vault optional
- schema remains `9`
- no destructive database migration

## Release gate

CI success is necessary but not sufficient for stable promotion.

Real-server validation must include:
- all Five Paths progression + anti-exploit matrix
- restart persistence
- GUI click/drag regression
- Contract claim/retry path
- API v1 compatibility
- API v2 ServicesManager discovery/snapshots/events
- Profile/leaderboard/PlaceholderAPI regression
- Mastery/Contracts/Resonance/Rebirth regression

Only after those checks pass should `v1.6.0` be promoted from testing candidate to stable.
