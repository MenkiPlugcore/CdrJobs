# CdrJobs v0.1.0 — The Runeborn

Status: Development baseline

## Goal

Establish the standalone CdrJobs core using the first profession, **Runebound Delver (Miner)**. This version is the foundation for every later profession.

## Added

### Profession progression
- Runebound Delver levels 1–100
- Fantasy rank titles based on profession level
- Configurable XP rewards for supported ore blocks
- Global Fate Essence milestone rewards

### Path of Ascension
Initial Miner skill tree:

- Stonewhisper
- Runebreaker
- Deepborn
- Gemseeker
- Echo of the Depth
- Heart of the Mountain

Skills support rank limits, profession-level requirements, prerequisite checks and Fate Essence costs.

### Persistence
- SQLite player profession progress
- SQLite skill ranks
- SQLite Fate Essence balance
- Persistent placed-ore tracking for anti XP exploitation

### Anti-exploit
Ore placed by a player is marked persistently. Breaking that marked ore does not award Miner profession XP, including after a server restart.

### Interface
- `/cdrjobs`
- `/cdrjobs stats [player]`
- `/cdrjobs skills`
- Miner profession menu
- Path of Ascension menu
- XP action bar feedback

### Administration
- `/cdrjobsadmin addxp <player> <amount>`
- `/cdrjobsadmin setlevel <player> <level>`
- `/cdrjobsadmin reset <player>`
- `/cdrjobsadmin reload`

### Integrations
- PlaceholderAPI support when installed
- No MENKIESTESParty dependency yet

## Future professions reserved

- Verdant Keeper — Farmer
- Bloodfang Stalker — Hunter
- Ironbark Warden — Lumberjack
- Tidebound Angler — Fisher

## Known development limits

- Profession Trials are not complete yet.
- Miner active abilities are not complete yet.
- Values are development values and still require live balancing.
- Public API and MENKIESTESParty integration are intentionally deferred.
