# CdrJobs v0.3.0 — Blood Moon

Adds **Bloodfang Stalker (Hunter)**.

## Core gameplay
- Configurable XP per hostile mob
- Spawn origin stored with PersistentDataContainer
- Spawner and breeding exclusions configurable
- Night-kill and dangerous-prey progression

## Path of Ascension
Predator's Instinct, Bloodtrail, Moonfang, Crimson Hunt, Soulmark, Warden's Oath, Apex Predator.

## Trials
- Trial of Fang: 300 valid kills
- Trial of the Crimson Moon: 1200 kills + 250 night kills + 10 dangerous prey

## Ability
`/cdrjobs ability hunter` activates Crimson Hunt: temporary Speed + profession XP boost. Cooldown persists in SQLite.

## Test checklist
- Normal configured hostile kill gives Hunter XP
- Spawner-born mob gives no XP when exclusion enabled
- Bred mob gives no XP when exclusion enabled
- Night kills count only at night
- Warden/Wither/Elder Guardian/Ravager/Evoker count as dangerous prey
- Trial gates block Crimson Hunt/Apex Predator correctly
- Cooldown survives restart
- Existing Miner/Farmer data remains intact
